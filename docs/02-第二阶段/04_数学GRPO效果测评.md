# 数学 GRPO 效果测评

| 项 | 内容 |
|---|---|
| 问题 | 用规则奖励（RLVR）训过之后，模型在数学题上到底变好了没有 |
| 对比对象 | `Qwen2.5-1.5B-Instruct`（原始）、`grpo_math15_r3`（GRPO 200 步，LoRA 叠加） |
| 裁判 | **无裁判**。规则判分：`\boxed{}` 抽取 + 数值归一化 + 容差 1e-6 |
| 样本 | MATH-500 全量 500 题 + AIME 90 题，零样本、贪心解码 |
| 上限 | 1024 token（**实测截断比仅 0.01，上限没有成为瓶颈**） |
| 种子 | 评测为贪心解码，无采样随机性 |
| 过程分析 | 同目录 `03_数学GRPO半量实跑日志与过程分析.md` |
| 原始输出 | `math15_results.csv`、`math15_results_grpo_math500.jsonl` |

## 零、结论速览

```text
MATH-500      40.0% -> 47.0%     +7.0 个百分点，p = 0.026，★ 统计显著
AIME           3.3% ->  2.2%     -1.1pt，p = 0.65，判不出来（样本太小）
格式合规率     93.4%（GRPO）     判分失败率 0
纯数值题       55.1%             最强的一档
分数题         36.6%             偏弱
表达式/选项    31.0%             最弱的一档

一句话：这是本项目第一次拿到统计显著的训练提升。
       第一阶段 4B 那轮 IFEval 看似涨了 13 个百分点，
       事后查明【全部来自判分器缺陷】，不是模型变化。
```

## 一、测评方法

**为什么不用模型裁判。** 本轮的奖励是**规则算出来的**（答案对不对），不是模型打的分。如果再用模型裁判测评，等于换一把不确定的尺子去量一把确定的尺子。直接用同一套规则判分，好处是**零噪声**——同一份回答重复判分结果完全相同。

**为什么只有两档而不是三档。** 第二阶段目前只训了一次（200 步）。没有"训 100 步"的中间档，所以是 `原始 → GRPO` 两点对比。**这是本次测评的结构性局限**（见第六节）。

**为什么评测上限设 1024。** 实测截断比只有 0.01，说明上限足够高、没有在测"能不能写完"。第一阶段 4B 那轮的教训是上限 640 时 100% 截断，那时测的其实是上限而不是模型。

**判分口径与训练奖励同构。** 奖励函数直接复用评测器的抽取/判分代码，并用单测确认「奖励=1.0 的样本」≡「评测判对的样本」。这保证了训练优化的目标与测评的指标是同一个东西——第一阶段的问题正是二者无关。

## 二、总览

| 指标 | 原始 | GRPO 后 | 变化 | 判据 |
|---|---|---|---|---|
| **MATH-500 准确率** | **40.0%** (200/500) | **47.0%** (235/500) | **+7.0pt** | **p = 0.026** |
| MATH-500 95% 置信区间 | [35.7%, 44.3%] | [42.6%, 51.4%] | 区间不重叠 | |
| AIME 准确率 | 3.3% (3/90) | 2.2% (2/90) | −1.1pt | p = 0.65，无差异 |
| 格式合规率（`\boxed{}`） | — | 93.4% (467/500) | — | 判分失败 0 条 |
| 撞长度上限比例 | — | 6.6% (33/500) | — | 上限未成为瓶颈 |

**统计检验**（两比例 z 检验，合并比例标准误 3.14pt）：

```text
z = 2.23   p = 0.0256
```

**p < 0.05，提升显著。** 这是本项目第一次有统计支撑的训练提升结论。

## 三、分层解读

### 1. 按答案类型分解（GRPO 侧）

| 答案类型 | 正确 / 总数 | 准确率 |
|---|---|---|
| **纯数值** | 174 / 316 | **55.1%** |
| 分数 | 26 / 71 | 36.6% |
| 表达式 / 选择题选项 | 35 / 113 | **31.0%** |

**纯数值题最强（55.1%），表达式类最弱（31.0%），差 24 个百分点。**

这个形态与任务性质一致：纯数值题的答案是单一数字，判分无歧义、模型也容易在 `\boxed{}` 里给出干净结果；而表达式题（如 `\frac{\sqrt{3}}{2}`）和选择题（如 `\text{(C)}`）对格式要求更高，判分虽已做了 LaTeX 归一化，但模型输出形式的多样性仍是难点。

> 注：因为 **base 的 MATH-500 逐题明细未落盘**，这一节**只有 GRPO 侧的数字，没有"提升了多少"的对比**。分层提升需要两侧明细齐全，属于待补数据。

### 2. 判分器质量：格式合规率 93.4%

```text
boxed    467/500 = 93.4%      模型按格式给出答案
lastnum   33/500 =  6.6%      靠"取末行数字"兜底
none       0/500 =  0.0%      判分器完全抓不到
```

**`none` 为 0 是本条最重要的信息**：没有任何一题因为"抓不到答案"而被判错，说明 47.0% 这个数字反映的是真实的解题能力，不是判分口径造成的假象。

### 3. 截断与正确性的关系

| 情形 | 正确 / 总数 | 准确率 |
|---|---|---|
| 未撞上限 | 234 / 467 | 50.1% |
| 撞上限 | 1 / 33 | **3.0%** |

**撞上限的题几乎全错（3.0%）**。这符合预期：推理链被截断时答案还没写出来，判分器只能靠 `lastnum` 兜底，几乎必错。

这条对本实验的结论有两面影响：

```text
好消息    截断只占 6.6%，不影响主结论
需留意    这 33 题里可能包含"模型其实会做、只是没写完"的题
          -> 真实能力可能略高于 47.0%，但上限同样是 40.0% 的基线受同样影响
          -> 同口径对比下不影响 +7.0pt 的结论
```

## 四、与第一阶段的对照：为什么这次的结论可信

第一阶段（Qwen3-4B）也做过 GRPO，但那次**测不出任何真实提升**：

| | 第一阶段（4B，通用奖励） | 本轮（1.5B，规则奖励） |
|---|---|---|
| 奖励来源 | InternLM2-1.8B-Reward 通用偏好分 | **规则判分（答案对不对）** |
| 奖励与评测的关系 | **无关**（偏好分 ≠ 数学对错） | **同构**（同一个判分函数） |
| 训练 reward 走势 | −1.04 → −0.47（抖动） | **0.710 → 0.805（五段单调上升）** |
| KL | 0.02（策略几乎不动） | 0.018（有位移且收敛） |
| 评测结果 | IFEval 96.2% vs base 98.1%（**没提升**） | **MATH-500 +7.0pt（p=0.026）** |
| 表面上的"提升" | IFEval 84.9% → 98.1% | — |
| ——那 13pt 的真实来源 | **判分器缺陷**（中文长度判分失效、结尾判分过严），修复后 base 就是 98.1% | 不适用 |

**三条证据在本轮互相印证**，这是判断"真的在学"的依据：

```text
训练侧    reward 五段单调上升，KL 有实质位移
判分侧    格式合规 93.4%，判分失败 0（信号没丢）
评测侧    MATH-500 +7.0pt，p < 0.05
```

第一阶段三项**同时不成立**：reward 抖动、KL 卡住、评测不动。

## 五、样例对照

### 题目：纯数值题（GRPO 最强的类型）

```text
base 在 MATH-500 上 40.0%，其中纯数值题的正确率构成主要贡献
GRPO 纯数值题 55.1% —— 这是 +7.0pt 的主要来源
```

### 题目：选择题选项（如 gold = `\text{(C)}`）

训练集里包含少量这类题（如 `['\\text{(C)}', '210', '9']`）。它们的判分依赖 LaTeX 归一化后与 `(C)` 精确匹配。

```text
表达式/选项类     31.0%      显著低于纯数值题
```

这提示一个可能的改进方向：**选择题本可以直接判选项字母**，但当前题面要求 `\boxed{}`，模型需要额外做一次"把选项搬进 boxed"的转换——这一步失败率较高。若能把这类题的判分口径放宽（接受裸选项字母），这类题的分数可能上升。

> 注意：这一类只占 113/500，即使全部修正也只影响约 22% 的题量，不会改变 +7.0pt 的主结论方向。

## 六、结论与局限

### 结论

```text
站得住的
    MATH-500  40.0% -> 47.0%，+7.0pt，p = 0.026（统计显著）
    格式合规率 93.4%，判分失败率 0（数字不是判分假象）
    训练侧 reward 与 KL 同步印证，不是孤立信号
    纯数值题 55.1% 是最强的一档，符合任务性质

判不出来的
    AIME  -1.1pt        p = 0.65，90 题单题权重 1.1pt，纯噪声
    分层提升幅度          base 逐题明细缺失，只有 GRPO 侧数字

没改善的
    表达式/选项类题      31.0%，明显偏低
    截断题（6.6%）       撞上限的题正确率仅 3.0%
```

### 局限一：只有单一随机种子

评测是**贪心解码**，所以评测本身没有采样噪声——这是规则判分相比模型裁判的优势。但**训练本身只跑了一次**，`+7.0pt` 里有多少来自训练随机性（数据顺序、rollout 采样）无法分离。

要下更强的结论，需要：

```text
同一配置训 2-3 次（不同 seed），看评测分数是否稳定在 47% 附近
```

这次没做。**不过 p=0.026 的统计检验已经排除了"纯属评测抽样巧合"这一可能**——它检验的是"两批 500 题的通过率差异是否可能来自同一总体"。

### 局限二：AIME 不构成任何证据

```text
base   3/90 = 3.3%
GRPO   2/90 = 2.2%
差     -1.1pt      p = 0.65
单题权重 100/90 = 1.1pt
```

90 题里差 1 题就是 1.1 个百分点。**3→2 的差异完全在噪声范围内，绝不能解读为"能力下降"**，也不该作为"提升"的反证。

AIME 的价值在于提供"难度上限"的参照：base 只有 3.3%，说明这类竞赛难度对 1.5B 基本不可解——这也正是训练数据必须做难度筛选的原因。

### 局限三：base 的逐题明细缺失

```text
缺失      math_results_base_math500.jsonl（评测时文件名与早期冒烟测试冲突，被覆盖）
影响      第三节按答案类型的分解只有 GRPO 侧，无法算"每类提升了多少"
          【总分对比不受影响】——base 与 GRPO 都是全量 500 题、同一套判分
待补      重跑一次 base 的 MATH-500 即可（约 57 分钟）
```

### 局限四：基线低于官方数字

```text
本实验 base      40.0%（零样本）
官方 Qwen2.5-1.5B-Instruct  55.2%（4-shot）
```

差 15 个百分点来自 shot 数差异（零样本 vs 4-shot），不是模型问题。**本实验要证明的是提升幅度，不是绝对水平。** 若要用绝对数字对外汇报，必须标注是零样本口径。

## 附：口径说明

```text
准确率          规则判分：抽取 \boxed{} -> LaTeX 归一化 -> 数值/字符串比对（容差 1e-6）
统计检验        两比例 z 检验（合并比例标准误），双尾 p 值
置信区间        正态近似 95% CI
格式合规率      抽取方式为 boxed 的比例（明细字段 how）
撞长度上限      明细字段 hit_cap，判据是生成长度达到 max_completion_length - 10
AIME 数字       以【评测日志 + 汇总 csv】为准；base 的 AIME 明细文件为更早一圈残留，不采用
评测解码        贪心（do_sample=False），故评测无采样随机性
思考模式        统一关闭（--no-think），评测与训练一致
```
